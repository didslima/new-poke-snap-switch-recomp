# Snap Recomp 1.3.0
## Known issues

- Windows SmartScreen may say "Windows protected your PC" because the exe is not code-signed. Click "More info", then "Run anyway".
- The updater inside 1.2.0 does not understand the one-exe format, so it cannot install this release for you. The last section says what to do.

## Saves and settings carry over

Updating keeps your saves and settings. Before anything changes, the updater copies them to a dated folder named update-backups next to the game's data and keeps the newest 3 copies. Going back to the previous version also makes a copy first. A portable install (portable.txt next to the exe) keeps everything in its own portable_data folder and carries it across the update.

Coming from 1.2.0 or earlier: the first start of the new install copies your saves and settings from the old per-user folder into the install folder. The old copy is left where it was.

## Driver notes

- NVIDIA: no known driver problems. Tested on driver version 621.14 with an RTX 4090.

## Changes

- Setup now names the real cause when it cannot read your game files: a keys file with no keys in it, a missing header_key, or a wrong game file. Before, every such failure was reported as a keys error ([#1](https://github.com/finalpantasy/new-pokemon-snap-recomp/issues/1)).

Also in this release:

One exe. The download is a single SnapRecomp.exe. On first run it is the setup and builds the game from your own dump. After that the same exe starts the game. There is no separate setup program any more.

Portable install. The build, the tools, saves, settings, caches and logs all stay in the folder that holds SnapRecomp.exe. Setup makes no shortcuts unless you tick them. You can move or rename the folder, and deleting it removes the game.

Command-line flags. Every option has a flag, so another launcher can start the game without our windows: `--play`, `--fullscreen`, `--windowed`, `--width`, `--height`, `--profile`, `--data-dir`, `--game` and `--yes` for setup, `--update`, `--check-install` and more. Run `SnapRecomp.exe --help` for the full list.

## Install or update

New install: put SnapRecomp.exe in a folder of its own and run it. Update: open the launcher and choose Updates. Version 1.2.0 and earlier cannot update to a one-exe release; download SnapRecomp.exe by hand, put it in a new folder and run setup once. Your saves are copied over on the first start. The Testing channel in the launcher's Updates page also offers early builds; Stable is the default.
